# Kiwoom Auto Trader — Windows 배포

이 저장소는 실행 파일과 업데이트 배포 전용입니다. 소스코드는 별도의 비공개 저장소에서 관리합니다.

## 실행

**[KiwoomAutoTrader.Updater.exe 다운로드](https://github.com/poolStackDeveloper/KiwoomAutoTrader-Releases/releases/latest/download/KiwoomAutoTrader.Updater.exe)**

Windows x64에서 위 파일 하나를 실행하세요. .NET 8 런타임을 포함하므로 별도 설치가 필요하지 않습니다.

1. 실행할 때 최신 버전을 확인합니다.
2. 새 버전은 서명·SHA-256 확인 후 자동 설치합니다.
3. 거래 프로그램을 실행합니다. 등록한 환경·계좌를 선택하고 **연결 · 자동매매**를 한 번 누르면 선택 전략 적용·연결·종목 검색·매수·청산 감시가 이어집니다. 실전에서는 붉은 ‘실전 연결 · 자동매매’ 버튼으로 구분합니다.
4. 실행 중에는 프로그램의 **업데이트 확인** 버튼으로 새 버전과 변경 사항을 확인하고 설치할 수 있습니다.

프로그램 실행 중에는 외부 업데이터가 강제 종료하지 않습니다. 앱 안에서 업데이트하려면 자동매매 중지·주문 잠금 후 미체결 및 V1 보유 포지션을 정리하세요. 설정·계좌정보·거래 기록은 업데이트 과정에서 유지됩니다.

일반 ‘중지’는 자동매매만 멈추며 주문 토글 상태는 유지합니다. 토글 OFF는 주문과 자동매매를 함께 잠급니다. 긴급 중지·연결 장애 시에도 토글은 OFF가 됩니다. 중지 후에는 ‘자동매매 재개’를 누릅니다. 잠금·긴급 상태는 자동으로 해제하지 않습니다. 전략 조건을 만족할 때만 주문합니다.

다운로드 및 변경 사항: [Releases](https://github.com/poolStackDeveloper/KiwoomAutoTrader-Releases/releases)

v1.5.0의 우측 **실시간 매매 모니터**에서 연결 준비 단계·경과 시간·검색 진행률·현재 검토 종목을 확인할 수 있습니다. 매수 검토 후보의 대기 사유, 전략 보유종목의 보호선/시간청산 조건, 이미 발생한 신호·진행 주문을 각각 표시합니다. 매수 검토는 확정 주문이나 체결 예측이 아닙니다. 최근 시세와 계좌 조회 시각, 중지/주문 잠금 상태도 함께 확인하세요.

v1.5.1은 누적 체결수량 중복 계산으로 발생하던 ‘전략 후보 준비 실패’ 오류를 수정합니다. 실시간 알림을 받으면 증권사 체결 내역을 재조회해 수량·금액을 대조하고, 확인된 미반영분만 적용합니다. 이전 기록은 암호화 보존하며 대조 가능한 상태는 재연결 때 자동 복구합니다. 대조 불일치는 주문 잠금과 구체적인 복구 안내로 표시합니다.

v1.6.0은 FHD/QHD에 맞춰 기본 최대화와 반응형 배치를 적용합니다. 상단 조작부는 전체 폭을 사용하고 QHD에서는 표·모니터·로그가 확장됩니다. 세로 공간이 좁으면 우측 모니터가 매수 검토/청산 감시/진행 주문 탭으로 전환됩니다.

v1.7.0은 보유종목·주문 내역의 **매수 사유 / 상세 보기**와 우측 청산 감시에 저장된 진입 근거를 표시합니다. 당시 장 초반 고점·현재가·VWAP·상승률·거래대금과 조건 충족 여부를 확인하세요. 연결 후 전략 기록이 복원되어야 표시되며 기록이 없으면 추정하지 않고 안내합니다. 하단 **로그 위 경계선**을 드래그해 로그 높이를 늘리거나 줄일 수 있습니다. 선택한 높이는 실행 중 유지하고 다음 실행에서는 화면에 맞는 기본 높이로 시작합니다.


v1.7.0에서 표의 종목을 선택하면 우측 **차트 · 호가**가 표시됩니다. 연결 후 수신한 체결의 1분봉(최근 90봉), 확보된 후보 종목의 일별 종가, **최우선 매수·매도호가**를 제공합니다. 접속 전 과거 분봉, 10단계 호가/잔량은 현재 제공하지 않습니다. 재연결하면 수신 분봉은 새로 수집합니다. QHD에서 공간이 충분하면 모니터와 차트를 함께 표시하고 작은 화면에서는 탭/세로 스크롤로 접근합니다. 표는 전체 재바인딩 대신 변경 행만 갱신하며 선택·스크롤과 모니터 텍스트 스크롤을 보존합니다.
v1.7.1부터 **FHD는 우측 실시간 매매 모니터 1개**, **QHD는 실시간 매매 모니터 + 차트·호가 2개**를 가로로 배치합니다. QHD 화면은 `종목 표 | 매매 모니터 | 차트·호가` 순서입니다. FHD에서 종목을 클릭해도 모니터는 계속 표시되고 차트로 전환되지 않습니다. 실제 창 폭 2,200px 이상 및 논리 폭 1,500px 이상을 기준으로 두 번째 패널을 표시하며, 창을 줄였다 넓혀도 선택 종목을 유지합니다. 이전 버전의 차트/모니터 탭 및 위아래 배치를 대체합니다.
v1.8.0의 첫 탭 **보유계좌**에서 선택 계좌의 국내주식 전체 보유분, 현재가·수량·평가금액·평가손익·수익률과 예수금·주문가능 현금·총자산을 확인하세요. 실시간 수신 시세는 1초마다 화면에 반영하고, 총자산은 증권사 조회 총자산에 이후 보유분 가격 변동만 반영한 **추정치**입니다. 예수금·보유수량은 기본 20초 계좌 조회 및 체결 알림으로 갱신됩니다. 조회 기준 총자산과 각 행의 시세 시각/상태도 표시합니다. 작은 창에서는 요약에 마우스를 올려 상세 갱신 정보를 볼 수 있습니다. 구독 한도 또는 거래정지 등으로 실시간 시세가 없는 보유분은 계좌 조회값을 표시합니다. 다른 계좌/해외주식/별도 상품의 통합 자산 화면은 아닙니다.
v1.9.0은 보유종목·보유계좌 금액에 천 단위 콤마를 표시하고 평가손익에 수익 빨강/손실 파랑과 굵은 글씨를 적용합니다. QHD 우측 차트에서 코스피/코스닥을 선택해 종목과 지수의 공통 첫 관측 대비 변화율을 비교하고 MACD(12,26,9), 스토캐스틱 Slow(14,3,3), RSI(14)를 함께 볼 수 있습니다. 지수는 약 20초 조회이며 장중 비교는 연결 후 자료만 사용합니다. 분봉 지표는 연결 후 수신 봉, 일별 지표는 확보된 과거 일봉 기준입니다. 자료가 부족하면 준비 상태를 표시하고 높이가 부족하면 패널 안에서 스크롤합니다. 이 지표는 화면 표시용으로 자동매매 조건에 추가되지 않습니다.

v1.10.0부터 재실행 후 계좌 연결·종목 선택 시 과거 **1분봉을 자동 조회**합니다. 차트 상단의 기준일을 바꿔 과거 날짜를 조회하고, ↻로 다시 조회, ◀/▶로 이전·다음 90봉 이동, **최신**으로 오늘의 최신 구간에 복귀할 수 있습니다. 최대 900봉/3페이지를 가져오며 과거·실시간 봉을 합치고 보조지표도 함께 계산합니다. 이력은 API에서 다시 가져오는 방식이므로 연결이 필요합니다. 지수 비교는 연결 이후 관측 구간만 제공합니다.

v1.11.0은 모니터 전체 재배치와 불필요한 외부 스크롤을 제거합니다. 긴 내용에만 내부 페이지 이동을 표시합니다. **전략 수익 리포트**에서 투자금을 직접 입력하거나 200/500/1,000만원을 선택하고, 과거 틱 자료로 선택 전략 또는 세 전략을 비교하세요. 일/월/연 수익률·누적 손익·거래 내역을 확인하고 HTML/JSON/CSV로 저장할 수 있습니다. 과거 자료가 없으면 미검증이며 합성 결과는 실제 성과가 아닙니다. 장기 틱 자동 수집이나 미래 수익 예측은 제공하지 않습니다.

v1.12.0부터 **파일 없이 리포트 실행**이 가능합니다. 등록 계좌를 선택하고 전략 수익 리포트에서 전략·투자금·기간을 고른 후 실행하세요. 키움 과거 일봉/1분봉을 자동 조회하며 기본 최근 7일(어제까지), 현재 시가총액 상위 보통주 5종목을 분석합니다. 기간 최대 32일·표본 최대 20종목, 진행률/중단을 지원합니다. 자동매매 연결은 필요하지 않습니다.

자동 분석은 **1분봉 근사**이며 분봉 내 가격 순서/거래량 배분/과거 호가를 가정하고 시장필터를 분석에서만 제외합니다. 현재 종목 표본 편향이 있고 초단타의 실제 틱 성과 검증은 아닙니다. 실제 확보 기간과 가정은 **데이터·분석 조건** 탭과 저장 리포트에 표시합니다. 월·연 통계는 확보 기간의 집계이며 미래 기대수익을 뜻하지 않습니다.

v1.12.1은 모든 조회·전략 거래·백테스트 표의 금액을 **천 단위 콤마/소수점 없음**으로 통일합니다. 손익은 **수익 빨강 Bold / 손실 파랑 Bold**이며 행 선택 후에도 유지됩니다. 수익률·지표는 소수점 두 자리를 유지하고 계산/저장 원값은 바꾸지 않습니다.

## 저장 위치

- 계좌 설정·거래 DB: `%LOCALAPPDATA%\KiwoomAutoTrader` (민감 payload는 Windows DPAPI 암호화)
- 프로그램 버전·업데이트: `%LOCALAPPDATA%\KiwoomAutoTraderUpdater`

인터넷이 끊기면 기존 설치가 있는 경우 검증한 기존 버전을 실행합니다. 첫 설치에는 인터넷이 필요합니다. 업데이트 파일의 RSA 서명 검증은 Windows Authenticode 코드 서명과 별개이며, 실행 파일에 Authenticode 서명은 적용되지 않았습니다.

## 모의투자

처음에는 키움 REST API의 모의투자용 App Key·Secret을 프로그램 설정에서 등록하세요. 모의·실전 모두 계좌번호 8자리 또는 10자리를 그대로 입력하며 하이픈 입력도 가능합니다. 숫자를 임의로 덧붙이지 마세요. 키·계좌정보를 GitHub Issue나 댓글에 올리지 마세요.

v1.11.0부터 메인 **적용 전략**에서 OpeningRangeMomentumV1(장초반 돌파) , MicroBreakoutScalpV1(초단타 최근 3분 돌파), 욱차트(WookChartV1·1분봉 과매도)을 선택합니다. 보유/미체결/미확인 주문이 있을 때는 변경을 막습니다. **전략 안내 / 추천**에서 규칙을 확인하세요. 세 전략의 실제 수익성은 미검증입니다.

KOSPI/KOSDAQ 후보 검색, 거래대금·추세 필터, 장 초반 고점 돌파 매수, 손절·수익보호·트레일링·15:10 청산을 자동 관리합니다. 장중 실행 시 당일 틱을 보충하고 실시간 누적량과 대조하며 준비가 끝난 종목부터 판단합니다. 전체 검색·보충에는 수분 이상 걸릴 수 있으며, 후보 탭에 대기 사유를 표시합니다. 조건이 없으면 거래하지 않습니다. 기존 수동 보유종목을 임의로 청산하지 않습니다.

자동매매 중지·프로그램 종료·연결 단절 시 자동청산도 실행되지 않습니다. 실제 주문·체결 연동과 전략 수익성 검증은 별도이며, 합성 백테스트 결과는 기대수익이 아닙니다.

욱차트는 완성 1분봉 Slow(14,3,3) K·D 모두 20 이하 + RSI(14) 30 이하에서 기본 K 상향교차를 확인합니다. 기본 손절 -0.7%, 익절 +1.2%, 최대 15분, 본전/트레일링 및 지표 회복 청산을 적용합니다. 과거 봉 복구 시 소급 주문하지 않습니다. 설정에서 기준을 바꿀 수 있으며 초기값은 최적화된 값이 아닙니다. 장초반 돌파와의 규칙/장단점 비교는 프로그램의 전략 안내에서 확인하세요. 실제 데이터가 없으므로 세 전략의 기대수익과 우열은 미검증입니다.

v1.11.1은 보유계좌·보유종목의 열을 **현재가→매입단가**, **보유수량→주문가능**, **평가금액→매입금액**, **평가손익→수익률** 순으로 묶습니다. 보유종목에도 매입금액·수익률을 표시하며 기존 천 단위 콤마·손익 색상·Bold를 유지합니다. 욱차트와 전략 리포트 등 v1.11.0 기능이 모두 포함됩니다.

v1.11.2는 보유계좌 상단의 총자산·주식평가·평가손익·수익률을 별도 영역으로 강조합니다. 손익과 수익률은 양수 빨강 Bold / 음수 파랑 Bold로 표시하고, 작은 화면에서는 한 줄 요약으로 표 공간을 유지합니다.
